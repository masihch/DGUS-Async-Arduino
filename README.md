# DGUS_Async

DGUS_Async is a lightweight asynchronous Arduino library for DWIN DGUS HMI displays.

## Features
- Async queue-based communication
- Event and stable event callbacks
- Multi-value write support
- Animation helper class
- Works with HardwareSerial and, where available, SoftwareSerial
